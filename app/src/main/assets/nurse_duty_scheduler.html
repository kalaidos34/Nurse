📱 APK 빌드 & 5×1 블러 위젯 적용 가이드

1. 첨부된 Android 프로젝트 ZIP으로 APK 생성

  1. 함께 제공된 NurseDuty_Android_Project.zip 압축을 풉니다.
  2. Android Studio에서 열고 상단 메뉴 [Build > Build Bundle(s) / APK(s) > Build APK(s)]를 클릭하면 설치용 app-debug.apk가 즉시 생성됩니다.
  3. PC에 Android Studio가 없다면 GitHub에 업로드 시 내장된 GitHub Actions 워크플로우가 자동으로 APK를 빌드해 줍니다.

2. 5×1 글래스 블러 홈 위젯 추가 방법

  1. APK 설치 후 안드로이드 홈 화면 빈 곳을 길게 누릅니다.
  2. [위젯] > [널스듀티 5×1 블러 위젯]을 선택해 홈 화면에 배치합니다.
  3. targetCellWidth="5", targetCellHeight="1" 및 반투명 블러 드로어블이 기본 적용되어 있습니다.

// 1. NurseDutyWidgetProvider.kt (5x1 글래스모피즘 블러 홈 위젯)
package com.example.nurseduty

import android.appwidget.AppWidgetManager
import android.appwidget.AppWidgetProvider
import android.content.Context
import android.graphics.Color
import android.widget.RemoteViews
import java.time.LocalDate

class NurseDutyWidgetProvider : AppWidgetProvider() {
    override fun onUpdate(context: Context, appWidgetManager: AppWidgetManager, appWidgetIds: IntArray) {
        val prefs = context.getSharedPreferences("nurse_duty_prefs", Context.MODE_PRIVATE)
        val today = LocalDate.now()

        for (widgetId in appWidgetIds) {
            val views = RemoteViews(context.packageName, R.layout.widget_nurse_duty_5x1)
            val dayIds = intArrayOf(R.id.day_1_title, R.id.day_2_title, R.id.day_3_title, R.id.day_4_title, R.id.day_5_title)
            val shiftIds = intArrayOf(R.id.day_1_shift, R.id.day_2_shift, R.id.day_3_shift, R.id.day_4_shift, R.id.day_5_shift)
            val holIds = intArrayOf(R.id.day_1_holiday, R.id.day_2_holiday, R.id.day_3_holiday, R.id.day_4_holiday, R.id.day_5_holiday)

            for (i in 0 until 5) {
                val d = today.plusDays(i.toLong())
                val key = d.toString() // YYYY-MM-DD
                val shift = prefs.getString("shift_$key", "Off") ?: "Off"
                val holiday = KoreanHolidays.getHolidayName(key)

                views.setTextViewText(dayIds[i], "${d.monthValue}/${d.dayOfMonth}")
                views.setTextViewText(shiftIds[i], shift)
                views.setTextViewText(holIds[i], holiday ?: "")
                if (holiday != null || d.dayOfWeek.value == 7) {
                    views.setTextColor(dayIds[i], Color.parseColor("#FDA4AF"))
                }
            }
            appWidgetManager.updateAppWidget(widgetId, views)
        }
    }
}
